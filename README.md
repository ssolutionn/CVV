# Никита Гольцев · сайт-портфолио

Продюсер событий и трансляций, Москва. Сайт: https://ssolutionn.github.io/CVV/

Статичная страница без сборки: всё лежит в `index.html`.

- `index.html` - сайт; у каждого проекта указана должность (как она называется в вакансиях) и масштаб роли.
- `og.png` - картинка превью ссылки 1200×630.
- `robots.txt`, `sitemap.xml` - для поисковиков.

Чтобы поправить должность или масштаб в полном списке, меняй у строки `data-pos` (ключи должностей из блока «Должности») и `data-s` (3 - вёл реализацию, 2 - отвечал за часть, 1 - отдельная задача), а также текст в `<div class="r">`. Счётчики пересчитываются сами.
